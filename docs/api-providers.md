# API 管理与 AI 服务提供商

Silly Chat 支持连接多种 AI 服务提供商，每个提供商可以配置多个 API 实例。

## 支持的 AI 提供商

| 提供商 | 说明 |
|------|------|
| **OpenAI** | 支持 GPT-3.5、GPT-4、GPT-4o 等模型 |
| **DeepSeek** | DeepSeek 系列模型 |
| **SiliconFlow** | SiliconFlow 提供的模型服务 |
| **Google / Gemini** | Gemini 系列模型（Gemini 2.5 Pro、Flash、1.5 系列等） |
| **Kimi / Moonshot** | 月之暗面 Kimi 模型 |
| **自定义 OpenAI 兼容** | 任何兼容 OpenAI API 格式的自定义服务端点 |

## API 配置属性

每个 API 实例包含以下配置：

| 属性 | 说明 |
|------|------|
| **显示名称** | API 的显示名称，便于识别 |
| **API 密钥** | 服务提供商的 API Key |
| **服务商** | 选择对应的 AI 服务提供商 |
| **模型名称** | 使用的具体模型名称 |
| **API 地址** | 自定义 API 端点 URL（自定义类型可配置） |
| **备注** | 附加说明信息 |
| **自定义请求体** | 支持覆盖默认请求体参数 |
| **模型列表** | 缓存的可用模型列表 |

## 模型选择

- 每个 API 可以指定使用的模型名称
- 支持自定义模型名称（输入任意模型 ID）
- 可缓存各服务商的模型列表便于快速切换
- 默认模型名称可在设置中单独配置

## 默认 API

- 可以设置一个默认 API，聊天中未指定 API 时自动使用
- 删除默认 API 后自动选择列表中第一个

## 连通性测试

支持测试 API 连通性：
- 发送一条简单测试消息（要求 AI 仅回复"好"字）
- 确认 API 密钥和端点配置正确

## 请求处理

- **流式响应 (SSE)**：实时逐字输出 AI 回复
- **自动重试与错误处理**：统一的错误提示和日志记录
- **Android 后台执行**：在 Android 设备上支持后台继续生成（显示通知）
- **请求中断**：支持随时取消正在进行的 AI 请求
- **HTTP 连接保持**：连接保持最长 4 分钟以加快响应速度

## API 管理功能

- **添加 API**：配置新的 API 连接
- **编辑 API**：修改已有 API 配置
- **删除 API**：移除不再使用的 API
- **设置默认**：选择默认使用的 API
