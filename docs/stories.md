# 故事管理

故事是支持多人互动的群聊场景。每个故事可以包含多个角色，提供统一的对话上下文。

## 故事属性

| 属性 | 说明 |
|------|------|
| **名称** | 故事的显示名称 |
| **简介 (Remark)** | 故事的简短描述 |
| **故事提示词 (Story Prompt)** | 故事的背景设定文本，会作为提示词的一部分发送给 AI |
| **分类** | 故事的分组标签，支持自定义分类管理 |

## 故事关联

故事可以关联以下内容：

- **角色列表**：故事中参与的 AI 角色（可包含临时角色）
- **世界书**：故事级别的世界书，在故事中所有对话都会激活
- **对话预设**：故事级别的提示词和模型参数配置

## 故事中的聊天

在故事下创建的聊天默认启用**群聊模式**，支持：

- 多角色轮流发言
- 手动触发任意角色发言（无需用户先输入）
- 角色之间自动互动

## 故事管理功能

- **创建故事**：新建故事场景并配置属性
- **编辑故事**：修改故事信息和关联内容
- **删除故事**：删除故事及其下属的所有临时角色
- **分类管理**：创建、重命名、删除和排序故事分类
- **排序**：拖拽排序故事列表

## 临时角色

当角色被创建时绑定了某个故事，该角色即成为该故事的临时角色：
- 临时角色不会出现在角色库中
- 删除故事时会同时删除其临时角色

## 数据迁移

系统会自动检测旧版本中不属于 `roles` 或 `stories` 目录的聊天文件夹，并将其转换为故事形式迁移到新数据格式中。
