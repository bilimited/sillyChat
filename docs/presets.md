# 对话预设与提示词

对话预设（Chat Option）是 AI 行为的完整配置方案，包括提示词模板、模型请求参数和正则规则。系统通过"提示词构建流水线"将角色设定、世界书、消息历史等内容组装成发送给 AI 的最终提示词。

## 预设类型

系统预置了几种不同复杂度的预设模板：

| 预设类型 | 说明 |
|------|------|
| **RP 预设 (Roleplay)** | 完整的角色扮演预设，包含角色定义、人物关系、用户设定、世界书、聊天回忆、作者注释等完整模块 |
| **Base 预设** | 基础预设，包含基本宏替换（时间、档案、用户名称），适合快速开始 |
| **空白预设** | 极简预设，只有消息列表，适合高级用户完全自定义 |
| **普通预设** | 包含角色定义和消息列表的简单预设 |

## 预设属性

每个预设包含以下配置：

### 提示词列表

预设包含一组按顺序排列的提示词模板，每个提示词可以指定：
- **内容**：提示词文本，支持宏替换
- **角色**：在发送给 AI 时的消息角色（system / user / assistant）
- **是否启用**：可临时禁用某个提示词
- **插入深度**：对于"聊天中"提示词，指定插入到消息历史的深度位置
- **优先级**：多个"聊天中"提示词的排序优先级
- **消息列表占位符**：标记该提示词为聊天消息历史的插入位置

### 模型请求参数

| 参数 | 说明 | 默认值 |
|------|------|------|
| **最大 Token 数** | AI 回复的最大生成长度 | 8000 |
| **温度 (Temperature)** | 回复的随机性，越高越有创意 | 0.95 |
| **核采样 (Top P)** | 核采样阈值 | 1.0 |
| **存在惩罚 (Presence Penalty)** | 话题新鲜度，降低重复 | 0.0 |
| **频率惩罚 (Frequency Penalty)** | 词频惩罚，减少重复用词 | 0.0 |
| **随机种子 (Seed)** | 固定随机种子以获得可复现结果 | -1（随机） |
| **最大历史长度** | 发送给 AI 的消息数量上限 | 64 |
| **流式响应** | 是否启用流式逐字输出 | 开启 |
| **思考模式** | 是否启用 AI 思考过程 | 关闭 |
| **删除思考标签** | 是否在发送给 AI 前删除 `<think>` 标签内容 | 开启 |

### 高级选项

- **合并消息列表**：将多条消息合并为一条（启用群聊格式化），每条消息前添加角色名称
- **聊天压缩**：提供两种压缩模式
  - **混合模式 (Mixin)**：将所有消息内容合并为单条消息
  - **分离模式 (Squash)**：将用户、AI、系统消息分别归类合并，添加角色标识前缀和后缀

## 提示词构建流水线

当用户发送消息时，系统按以下步骤构建最终发送给 AI 的提示词：

1. **世界书激活**：扫描消息内容，匹配并激活世界书条目
2. **世界书插入提示词**：将激活的条目内容插入到提示词模板的对应位置（如 `{{lore before_char}}`）
3. **宏替换**：处理提示词中的各种宏变量（`{{char}}`、`{{user}}`、`{{archive}}` 等）
4. **聊天中提示词插入**：将标记为"插入到聊天"的提示词按深度插入消息历史
5. **@D 世界书插入**：将位置为 @D 的世界书条目按深度插入消息历史
6. **格式化主内容**：如果启用格式化，在最终阶段对消息内容进行宏替换
7. **合并相邻消息**：将相同角色的相邻消息合并

## 预设管理功能

- **创建预设**：选择预设类型模板创建新预设
- **编辑预设**：修改提示词列表、请求参数、正则规则
- **删除预设**：移除不再需要的预设
- **排序**：拖拽排序预设列表（第一个为默认预设）
- **导出预设**：导出预设配置文件（支持 ST 兼容格式）

## 预设优先级

系统按以下优先级决定使用哪个预设：
1. 聊天角色绑定的预设（最高优先级）
2. 故事绑定的预设
3. 全局默认预设（列表中的第一个）

## 提示词管理

除了预设中的提示词，系统还提供独立的提示词管理功能：
- 创建可复用的提示词模板
- 提示词可以在多个预设之间共享引用
- 支持提示词的启用/禁用

## 提示词预览

允许在发送前查看完整的提示词组装结果，方便调试和优化提示词效果。
