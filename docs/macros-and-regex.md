# 宏系统与正则规则

## 宏系统

Silly Chat 的宏（Macro）系统用于在提示词和消息中进行动态文本替换。宏使用 `{{macro_name}}` 格式，在发送请求前被替换为实际值。

### 内置宏

| 宏 | 说明 |
|------|------|
| `{{user}}` | 当前用户的名称 |
| `{{char}}` | 当前发言角色的名称 |
| `{{archive}}` | 角色的详细档案信息 |
| `{{description}}` | 当前聊天的描述/作者注释 |
| `{{relations}}` | 当前角色与其他角色的关系列表 |
| `{{recent-characters:x}}` | 最近 x 条消息中提及但不在关系列表内的角色简介 |
| `{{time}}` | 当前系统时间 |
| `{{userbrief}}` | 用户的简短介绍 |
| `{{extraprompt}}` | 额外的提示词内容 |
| `{{lastuserMessage}}` | 最后一条用户消息的内容 |
| `{{msg}}` | 当前消息内容（用于消息模板） |

### 世界书插入宏

用于指定世界书条目在提示词中的插入位置：

| 宏 | 说明 |
|------|------|
| `{{lore before_char}}` | 在角色定义前插入世界书 |
| `{{lore after_char}}` | 在角色定义后插入世界书 |
| `{{lore before_em}}` | 在作者注释前插入世界书 |
| `{{lore after_em}}` | 在作者注释后插入世界书 |
| `{{lore memory}}` | 在聊天回忆区域插入世界书 |
| `{{lore xxx default=xxx}}` | 为 position 为 x 的世界书条目指定默认内容（无匹配时使用） |

### SillyTavern 兼容宏

系统兼容部分 SillyTavern 的动态宏语法：

| 宏 | 说明 | 示例 |
|------|------|------|
| `{{setvar::key::value}}` | 设置变量 key 的值为 value，并从文本中移除 | `{{setvar::mood::happy}}` |
| `{{getvar::key}}` | 获取变量 key 的值并替换 | `{{getvar::mood}}` → `happy` |
| `{{addvar::key::value}}` | 将 value 追加到变量 key 的末尾 | `{{addvar::log::事件}}` |
| `{{random::a,b,c,d}}` | 从逗号分隔的列表中随机选取一项 | `{{random::晴天,雨天,阴天}}` |
| `{{roll NdX}}` | 模拟掷骰子，N 个 X 面骰子，返回总和 | `{{roll 2d6}}` → `7` |

宏支持嵌套处理，系统会循环替换直到没有更多可处理的宏。

## 正则规则系统

正则规则用于在发送和接收消息时进行文本替换处理。规则使用 JavaScript 风格的正则表达式。

### 规则应用时机

| 时机 | 说明 |
|------|------|
| **发送时 (onRequest)** | 在将消息发送给 AI 之前应用 |
| **接收时 (onAddMessage)** | 在将 AI 回复添加到消息记录时应用 |
| **渲染时 (onRender)** | 在消息显示到界面时应用 |

### 规则作用域

| 作用域 | 说明 |
|------|------|
| **用户消息** | 正则仅应用于用户发送的消息 |
| **AI 消息** | 正则仅应用于 AI 生成的消息 |
| **深度范围** | 限制正则仅应用于最近 N 条消息（-1 表示无限） |
| **角色限制** | 可指定仅对特定角色生效 |

### 正则规则配置

每个规则包含：
- **名称**：规则描述
- **正则表达式**：JS 风格的正则（支持 `/pattern/flags` 格式，如 `/hello/gi`）
- **替换文本**：匹配后的替换内容（支持 `$1`、`$2` 等捕获组引用）
- **修减文本**：直接删除的文本内容（每行一个）
- **启用状态**：可临时禁用规则

### 规则级别

- **全局正则**：在设置中配置，对所有聊天生效
- **预设正则**：在每个对话预设中配置，仅对使用该预设的聊天生效

### 使用场景

- **格式清理**：删除 AI 回复中不需要的前缀或后缀
- **角色名替换**：将 AI 回复中的特定称呼替换为角色名
- **内容过滤**：屏蔽或替换不当内容
- **格式转换**：统一消息的排版格式
- **输出美化**：添加 Emoji、格式化特殊标记等
