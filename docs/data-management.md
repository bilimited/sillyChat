# 数据管理

Silly Chat 采用基于文件的本地数据存储，并提供完善的数据导入导出和云同步功能。

## 仓库系统 (Vault)

### 什么是仓库

仓库是一个独立的数据存储空间，包含该场景下的所有角色、聊天记录、设置等数据。每个仓库相当于一个"项目"或"存档"。

### 多仓库管理

- **创建仓库**：新建独立的存储空间
- **切换仓库**：在不同仓库之间切换（需要重启应用）
- **默认仓库**：首个仓库名为 `SillyChat`，位于应用文档目录下

### 仓库目录结构

每个仓库的数据存储在 `{应用目录}/SillyChat/{仓库名}/` 下：

| 文件/目录 | 内容 |
|------|------|
| `settings.json` | 仓库设置（API、正则、显示、提示词设置等） |
| `characters.json` | 角色数据 |
| `stories.json` | 故事数据 |
| `prompts.json` | 提示词模板 |
| `chat_options.json` | 对话预设 |
| `lorebooks.json` | 世界书数据 |
| `chat_index.json` | 聊天元数据索引 |
| `recent_chat.json` | 最近聊天记录 |
| `chats/roles/{角色ID}/` | 各角色的聊天文件 (`.chat`) |
| `chats/stories/{故事ID}/` | 各故事的聊天文件 (`.chat`) |
| `.imgs/` | 图片文件存储 |

## 数据导出

### 本地导出

将当前仓库的所有数据打包导出：
- 自动将仓库目录压缩为 ZIP 文件
- 文件名包含仓库名和时间戳（如 `SillyChat_20260101_120000.zip`）
- 使用系统文件选择器选择保存位置

### 导出预设

支持将对话预设导出为 JSON 文件：
- 导出格式兼容 SillyTavern 的预设格式
- 可选择导出位置

## 数据导入

### 本地导入

从 ZIP 备份文件恢复数据：
- 选择之前导出的 ZIP 文件
- **导入将覆盖当前仓库中的所有数据**
- 导入完成后自动重启应用

## WebDAV 云同步

支持通过 WebDAV 协议进行云端备份和恢复：

### 配置 WebDAV

需要配置以下信息：
- **WebDAV 服务器地址**
- **用户名**
- **密码**

### 云端备份

- 将当前仓库压缩为 ZIP 并上传到 WebDAV 服务器
- 上传路径：`/SillyChatFiles/{仓库名}.zip`
- 显示上传进度

### 云端恢复

- 从 WebDAV 服务器下载备份文件
- 显示备份文件的日期和大小信息
- 确认后覆盖本地数据并重启应用

## 首次启动

首次启动应用时会：
1. 显示引导页面
2. 自动初始化数据（预置 API 配置模板、对话预设、示例角色等）

## 数据安全

- 所有数据存储在本地设备上
- 不会自动上传到任何服务器（除非手动配置 WebDAV）
- API 密钥保存在本地设置文件中
