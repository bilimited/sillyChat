# 外观设置

Silly Chat 提供丰富的外观定制选项，让界面更符合个人喜好。

## 主题设置

### 亮色/暗色模式

- 一键切换亮色和暗色主题
- 自动适配系统级别的 Material 3 设计规范

### 主题配色

- 支持多种预设主题配色方案（基于 FlexColorScheme）
- 自定义主题色，通过颜色选择器自由选择
- 亮色和暗色模式使用独立的配色方案

## 字体设置

### 全局字体

- 自定义全局字体名称，修改应用所有文本的字体
- 支持加载自定义字体文件：
  - 从设备中选择 `.ttf` 或 `.otf` 字体文件
  - 自动复制到应用目录并加载
  - 支持自定义字体族名称
  - Windows 平台直接引用字体文件路径

### 内置字体

- 集成了 MiSans 字体

## 头像样式

支持调整头像的显示样式：
- **圆形 (Circle)**：圆形裁剪头像
- **圆角矩形**：带有圆角的方形头像
- 其他自定义样式

## 其他显示设置

在显示设置中还包含以下配置项：

- **文本缩放**：应用全局文本缩放系数为 0.95
- **消息气泡样式**：自定义对话气泡的外观

## 设置页面结构

外观设置页面整合了以下配置区域：

| 区域 | 功能 |
|------|------|
| **主题** | 配色方案选择、自定义颜色 |
| **字体** | 全局字体名称输入、自定义字体文件加载 |
| **头像** | 头像显示样式切换 |
| **预览** | 聊天界面实时预览效果 |

## 设置持久化

所有外观设置保存在当前仓库的 `settings.json` 文件中，切换仓库后可以有不同的外观配置。
