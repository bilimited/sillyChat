# 角色管理

角色是 Silly Chat 的核心元素。每个角色代表一个 AI 可以扮演的人格，包含丰富的属性信息和关系网络。

## 角色属性

每个角色包含以下信息：

| 属性 | 说明 |
|------|------|
| **名称 (Remark)** | 角色的显示名称 |
| **唯一名称 (Role Name)** | 角色的唯一标识名，用于提示词中引用 |
| **头像 (Avatar)** | 角色的头像图片 |
| **背景图片** | 对话界面的背景图 |
| **简介 (Brief)** | 角色的简短介绍 |
| **档案 (Archive)** | 角色的详细设定信息，将作为提示词的一部分发送给 AI |
| **描述 (Description)** | 角色的描述信息 |
| **开场白 (First Message)** | 与新角色开始对话时，AI 自动发送的第一条消息 |
| **更多开场白** | 备选的开场白列表，可以在聊天中切换不同的开场白 |
| **分类** | 角色的分组标签，支持自定义分类管理 |

## 消息风格

每个角色可以设置三种消息风格：

- **普通 (Common)**：标准的对话风格
- **旁白 (Narration)**：叙事性风格，适合叙述场景
- **总结 (Summary)**：用于生成摘要的特殊风格

## 角色关系

角色之间可以建立关系网络：

- 为角色设定与其他角色的关系类型（如朋友、敌人、家人等）
- 添加关系简述说明两者之间的联系
- 关系数据可在提示词中通过 `{{relations}}` 宏引用
- 支持通过关系图谱可视化查看角色之间的关联

## 角色关联设置

角色可以绑定以下内容以增强对话体验：

- **世界书**：角色专属的知识条目集合，对话中自动激活
- **记忆书**：专用于存储和回顾对话记忆的世界书
- **对话预设**：角色专属的提示词和模型参数配置，会覆盖聊天的默认预设
- **故事绑定**：角色可作为临时角色从属于某个故事

## 角色管理功能

- **创建角色**：新建空白角色并编辑各属性
- **编辑角色**：修改已有角色的所有属性和设定
- **删除角色**：移除不再需要的角色
- **角色画廊**：以卡片形式浏览所有角色
- **联系人列表**：按分类整理和查看角色
- **分类管理**：创建、重命名、删除和排序角色分类
- **剪贴板**：支持复制角色的设定内容

## 内置角色

系统预置了以下特殊角色：

- **默认助手 (ID: -1)**：当聊天未指定角色时的默认 AI 助手
- **我 (ID: 0)**：代表用户自身，可在设置中切换
- **总结姬 (ID: -2)**：专用于生成对话摘要的特殊角色

## 数据存储

角色数据保存在当前仓库的 `characters.json` 文件中，分类配置保存在 `contact_categories.json` 文件中。
