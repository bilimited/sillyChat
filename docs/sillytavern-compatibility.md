# SillyTavern 兼容性

Silly Chat 提供了与 SillyTavern (ST) 的兼容功能，支持从 ST 导入数据和导出 ST 兼容格式的配置。兼容性为实验性质，不追求完整的 ST 功能对等。

## SillyTavern 数据导入

通过设置页面的"从 SillyTavern 导入"功能，可以导入以下类型的数据：

### 角色卡导入

- **支持格式**：PNG 格式的角色卡图片（图片中嵌入 JSON 元数据）
- **导入内容**：
  - 角色名称和昵称
  - 角色描述和个人信息
  - 角色头像（从 PNG 图片中提取）
  - 开场白
  - 替代问候语
  - 创作者信息和版本
- **处理流程**：
  1. 读取 PNG 文件的 EXIF/文本块中的 JSON 数据
  2. 解析角色属性
  3. 用 PNG 图片作为角色头像
  4. 添加到当前角色库

### 世界书导入

- **支持格式**：SillyTavern 世界书 JSON 文件
- **导入内容**：
  - 世界书名称
  - 所有条目的键、内容和位置
  - 扫描深度设置
  - 条目优先级
  - 条目启用状态

### 正则规则导入

- **支持格式**：SillyTavern 正则配置 JSON 文件
- **导入内容**：
  - 正则表达式和替换文本
  - 作用范围（用户消息、AI 消息）
  - 启用状态

### 配置导入

- **支持格式**：SillyTavern 设置配置文件
- **导入内容**：
  - 模型参数（温度、Top P 等）
  - 提示词模板
  - 部分全局设置

## SillyTavern 宏兼容

系统兼容 SillyTavern 的动态变量宏语法：

- `{{setvar::key::value}}` — 设置变量
- `{{getvar::key}}` — 获取变量
- `{{addvar::key::value}}` — 累加变量
- `{{random::a,b,c,...}}` — 随机选择
- `{{roll NdX}}` — 掷骰子

详见 [宏系统与正则规则](macros-and-regex.md)。

## 预设导出

支持将对话预设导出为兼容 SillyTavern 的 JSON 格式：

- 导出提示词模板
- 导出请求参数
- 导出正则规则配置

## 导入注意事项

- 导入的数据可能与原始 ST 数据不完全一致，部分高级功能可能不被支持
- 角色卡中的某些自定义字段可能被忽略
- 世界书的位置映射可能与 ST 有差异
- 正则语法的处理逻辑尽力兼容，但复杂的 JS 正则可能有细微差别
- 建议导入后检查数据的完整性
