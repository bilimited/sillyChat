# 其他功能

## 日志系统

Silly Chat 内置了运行日志记录功能：

- **日志类型**：信息 (Info)、警告 (Warning)、错误 (Error)
- **日志内容类型**：文本和 JSON 数据
- **日志查看**：在设置页面可查看最近的运行日志
- **未读计数**：显示未查看的日志数量
- **日志上限**：最多保留 30 条日志记录
- **错误捕获**：自动捕获 Flutter 层面的异常并记录

## 应用更新日志

- 启动时自动检测版本变化
- 如果有新版本变更，显示更新日志对话框
- 更新日志以 Markdown 格式渲染展示

## Markdown 渲染

聊天消息支持 Markdown 格式的富文本渲染：

- 标题、列表、引用等标准 Markdown 语法
- **代码块**：带语法高亮的代码显示
- **LaTeX 数学公式**：支持行内公式和块级公式渲染
- **`<think>` 标签**：特殊折叠显示 AI 的思考过程内容

## 关系图谱

提供角色关系的可视化展示：

- 基于 WebView 的交互式关系图谱
- 节点代表角色，边代表关系
- 按角色分类着色
- 支持拖拽和缩放交互

## 状态栏

- 底部状态栏显示当前连接状态
- 显示 AI 生成进度（"正在激活世界书..."、"生成中..."等）
- 基于 WebView 渲染

## Token 估算

- 在发送请求前估算提示词的 Token 数量
- 帮助用户了解上下文使用情况，防止超出模型限制

## 消息压缩

当聊天消息过长时，支持对历史消息进行压缩：

- **混合模式**：将所有历史消息合并为一条用户消息
- **分离模式**：将用户、AI、系统消息分别归类压缩，添加角色标识

## 消息优化

提供消息优化工具，帮助改善提示词效果。

## 聊天详情

查看单个聊天文件的统计信息：
- 消息总数
- 消息总字数
- 文件大小和路径

## Android 后台运行

在 Android 平台上：
- AI 生成时自动启动前台服务
- 通知栏显示"少女祈祷中..."的状态提示
- 所有生成任务完成后自动退出后台模式

## 引导页面

首次启动应用时显示引导页面，帮助新用户快速了解应用功能。

## 项目信息

- 显示应用版本号
- 应用名称和基础信息
