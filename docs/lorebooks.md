# 世界书 / 知识书

世界书是一个上下文注入系统，由多个知识条目组成。当对话中出现条目的触发关键词时，该条目的内容会自动插入到 AI 的提示词中，增强 AI 对设定和背景的了解。

## 世界书类型

系统支持三种类型的世界书：

| 类型 | 说明 |
|------|------|
| **全局世界书 (World)** | 在库级别全局激活，适用于所有聊天 |
| **角色书 (Character)** | 绑定到特定角色，仅在该角色的聊天中生效 |
| **记忆书 (Memory)** | 专用于存储和回顾对话记忆，可绑定到角色 |

## 世界书属性

| 属性 | 说明 |
|------|------|
| **名称** | 世界书的显示名称 |
| **扫描深度** | 在最近几条消息中扫描触发关键词（数值越大扫描越多） |
| **最大 Token** | 激活的条目内容总 token 数上限，防止超出 AI 上下文限制 |

## 知识条目属性

每个世界书包含多个条目，每个条目包含：

| 属性 | 说明 |
|------|------|
| **键 (Key)** | 触发关键词列表，逗号分隔。当对话中出现这些词时激活条目 |
| **内容 (Content)** | 被激活时插入到提示词中的文本内容 |
| **位置 (Position)** | 条目在提示词中的插入位置 |
| **优先级** | 多个条目同时激活时的排序优先级 |

### 位置类型

条目可以插入到提示词的不同位置：
- **`before_char`**：在角色定义之前
- **`after_char`**：在角色定义之后
- **`before_em`**：在作者注释之前
- **`after_em`**：在作者注释之后
- **`@D`**：在聊天消息中的指定深度位置插入（@D0 = 最后一条消息之后，@D1 = 倒数第一条之前，以此类推）
- **`memory`**：在聊天回忆区域

## 世界书激活

### 自动激活

世界书根据消息内容自动激活条目：
1. 扫描指定深度内的消息内容
2. 匹配条目的触发关键词（支持逗号分隔的多关键词）
3. 按优先级和 Token 限制筛选激活的条目
4. 将激活的内容插入到提示词对应位置

### 全局激活

在世界书管理页面可以将某个世界书设为全局激活状态，使其在所有聊天中生效。

### 手动激活

在聊天中可以手动切换某个世界书条目的激活状态。

## 世界书管理功能

- **创建世界书**：新建空白世界书，选择类型
- **编辑世界书**：修改名称、扫描深度、Token 上限
- **删除世界书**：移除不再需要的世界书
- **添加条目**：在世界书中添加新的知识条目
- **编辑条目**：修改条目的键、内容、位置等
- **删除条目**：移除条目
- **条目剪贴板**：支持复制粘贴条目
- **排序**：拖拽排序世界书列表

## 使用场景

- **角色设定补充**：将角色相关的世界观、背景设定作为世界书条目，在对话相关话题时自动插入
- **剧情推进**：预设剧情发展节点，当对话到达特定内容时触发
- **知识库**：构建专业知识条目，让 AI 在需要时自动获取准确信息
- **记忆系统**：将对话中的关键信息提取为记忆条目，在后续对话中自动回顾
